# 日报、周报与 Markdown 导出

仅生成报告时无需禅道登录。按 SKILL.md 第2、3节采集和整理；用户指定工具时，必须向采集脚本传入 `--tools`，只采集所选工具。

- 日报未指定日期取今天；周报或本周工作未指定范围取本周一至今天。向采集脚本传入对应具体日期，展示实际范围。
- 日报按项目整理当天事项及结果；周报包含本周概览、逐日进展和有证据的待办。用户提供模板时遵从模板。
- 标明数据来源范围及缺失记录，保留内部来源索引用于核对；导出正文不包含原始对话、凭据及无关个人内容。
- 区分计划、进行中和已完成；不根据消息数量推测工时。报告模式不套用禅道登记的每日8小时分配规则。
- 空白日期说明无可用记录，不编造工作；允许用户补充线下事项。纯本地报告可直接保存供用户审阅，无需禅道提交确认。

模型先把正文写为 UTF-8 Markdown 草稿，建议命名 `工作日报-YYYY-MM-DD.md` 或 `工作周报-YYYY-MM-DD至YYYY-MM-DD.md`，再运行：

```text
python <技能目录>/scripts/export_report.py --input <本次运行目录>/report.md --name 工作周报-2026-09-14至2026-09-15.md
python <技能目录>/scripts/export_report.py --input <本次运行目录>/report.md --output-dir <用户指定的绝对目录> --name 工作周报-2026-09-14至2026-09-15.md
```

路径有空格时需加引号；示例日期仅演示。目录规则：本次指定 > `~/.zentao-worklog/preferences.json` 中 `report_output_dir` > 当前用户系统下载文件夹。Windows 优先读取系统配置的下载位置，未配置时回退 `~/Downloads`。

用户明确指定输出目录，成功导出后默认记住；用户说“仅这次”时加 `--no-remember`，保留原偏好。`~/.zentao-worklog/` 保存偏好，最终报告按上述规则保存。同名文件自动添加编号，保留已有文件。偏好目录不可用时报告错误，不擅自改存其他位置。

保存后读取脚本的 `path`，在最终回复**明确给出完整绝对路径和可点击文件链接**，说明报告日期范围。首次记住目录时告知“以后默认保存到此目录”。有 warning 时同时说明；导出成功不代表禅道日志已提交。

报告草稿固定保存到 workspace.py create 返回的 report 路径，最终导出成功后按 SKILL.md 清理内部临时文件。
